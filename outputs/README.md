# Published Analysis Outputs

This folder contains the completed public data outputs for the Formula 1 Race Analytics project.

## Files

- `dataset_inventory.csv` summarises the Formula 1 tables available for analysis.
- `latest_race_results.csv` contains the latest race results.
- `latest_race_podium_and_points.csv` gives a compact podium and points view.
- `recent_season_race_counts.csv` summarises race counts by recent season.
- `top_result_statuses.csv` summarises common race result statuses.
- `fastest_average_pit_stop_driver_ids.csv` contains the pit-stop comparison output.
- `race_analytics_output_summary.md` explains the outputs and analysis.

Related charts are published in the repository's `assets/` folder.
