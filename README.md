# Formula 1 Race Analytics — Completed

**Status: Completed.** This repository publishes a focused Formula 1 race-results analysis with a FastF1 refresh script, curated output tables, analysis summaries, and chart assets.

## Delivered

- FastF1-based refresh script for the latest completed race
- Race result and podium/points CSV outputs
- Season race counts, result-status summaries, and pit-stop analysis outputs
- Dataset inventory and documented data outputs
- SVG chart assets for dataset coverage and latest race points

## Repository contents

- `src/update_latest_race_results.py` refreshes the latest completed race output.
- `outputs/` contains the published CSVs and analysis summary.
- `assets/` contains the chart assets.
- `data/` and `dashboards/` document the available source data and reporting context.

## Related project

The broader [Formula 1 Analytics pipeline](https://github.com/eswarsurya/formula1-analytics) is also marked Completed and covers reusable ETL scripts, data cleaning, and race-performance analysis.
